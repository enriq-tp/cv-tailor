# Architecture

Status: Phase 1, Task 1 (scaffold). Only the generated Next.js structure exists. Planned folders are listed separately below and are created when a task first needs them.

## Current structure

```
cv-tailor/
├─ .claude/            Claude Code project settings (plugins)
├─ docs/wiki/          Project wiki: index, architecture, decisions, changelog
├─ public/             Static files served as-is at the site root (SVGs from the template)
├─ src/
│  └─ app/             Next.js App Router: routes, layouts, global CSS
│     ├─ layout.tsx    Root layout wrapping every page (html/body, fonts, metadata)
│     ├─ page.tsx      The "/" route (still the create-next-app placeholder)
│     ├─ globals.css   Global styles, Tailwind is loaded here
│     └─ favicon.ico
├─ CLAUDE.md           Project rules for Claude Code
├─ AGENTS.md           Generated by Next.js: points coding agents to the bundled docs
├─ eslint.config.mjs   ESLint rules (Next.js + TypeScript, Prettier last)
├─ next.config.ts      Next.js config (Tailwind loader for Turbopack, caching flags)
├─ tsconfig.json       TypeScript config, "strict": true, alias @/* -> src/*
├─ package.json        Dependencies and scripts (dev, build, lint, format)
├─ .prettierrc         Prettier formatting rules
└─ .prettierignore     Files Prettier must not touch
```

Generated and not committed: `node_modules/`, `.next/` (build output), `next-env.d.ts`.

## Planned folders (not created yet)

| Folder              | Purpose                                                                                                 | Phase |
| ------------------- | ------------------------------------------------------------------------------------------------------- | ----- |
| `src/lib/`          | Server logic: PDF text extractors (`src/lib/extractors/`), logger, DB client, zod schemas, helpers      | 1     |
| `src/components/`   | Reusable UI components                                                                                  | 1     |
| `src/agents/`       | Orchestrator that calls the Claude API: extract CV JSON, match with job, rewrite JSON                   | 2     |
| `prisma/`           | Prisma schema and migrations                                                                            | 1     |
| `docker-compose.yml`| Local Postgres                                                                                          | 1     |

Rule of thumb: UI lives in `src/components/` and `src/app/`; anything that talks to the database, the filesystem or an external API lives in `src/lib/` or `src/agents/` and runs on the server only.

## Data flow (target)

PDF -> text loader -> cleaning -> LLM extracts structured JSON (zod) -> match against job JSON -> LLM rewrites only the JSON -> fixed PDF template (`@react-pdf/renderer`) -> PDF. See `CLAUDE.md` for the rules around it.

## Tooling notes

- ESLint (`npm run lint`) finds code problems; Prettier (`npm run format`) only formats. `eslint-config-prettier` turns off ESLint rules that would fight Prettier.
- `next.config.ts` was generated with `cacheComponents` and `partialPrefetching` enabled. These are defaults of the current Next.js template and change how rendering and caching work; revisit when the first real pages are built.
